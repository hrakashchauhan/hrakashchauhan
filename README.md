# Akash Kumar

### Engineer who ships end-to-end — AI/ML applications & real-time web 🛠️

I'm a builder who ships. I work across AI/ML, full-stack web apps, and health/productivity tools — designing, building, and deploying end-to-end products. I'm focused on **software engineering** and **open to SWE internships**, with a long-term interest in product. I care about clear problem framing, fast iteration, and tools that respect the people using them.

Most of my recent work centers on practical applications of LLMs (Gemini, MedGemma) and real-time web experiences. I prefer building the whole thing — from the data layer to the UI — so I understand the trade-offs that matter.
